# Lightroom-Plugin---Streamdeck-Preset-Shortcut

## Concert LED Skin Fix presets (Lightroom, the cloud app formerly "Lightroom CC")

These are one-click presets for fixing skin tones on performers lit by coloured LED stage light. Each preset changes **only the Red, Green and Blue channel point curves**. Everything else stays as you set it: exposure, white balance, HSL, profile, the master RGB curve and the process version. That means you can stack a preset on top of an edit you've already started.

### What's included

There are 8 light-colour casts, each in 3 strengths, plus 1 reset preset, for 25 presets in total. They all sit in the preset group **Concert LED Skin Fix**.

| # | Preset | Use when the light is… | What the curves do |
|---|--------|-------------------------|--------------------|
| 01 | Red Wash | red / crimson | Red ↓ (with a lowered red white point), Green ↑, Blue ↑ |
| 02 | Orange-Amber Wash | orange, amber, warm tungsten-style LED | Red ↓, Green slightly ↑, Blue ↑↑ |
| 03 | Yellow Wash | yellow | Red slightly ↓, Green ↓, Blue ↑↑ |
| 04 | Green Wash | green | Red ↑, Green ↓, Blue slightly ↑ |
| 05 | Cyan-Teal Wash | cyan / teal / aqua | Red ↑↑, Green ↓, Blue ↓ |
| 06 | Blue Wash | blue | Red ↑, Green ↑, Blue ↓↓ |
| 07 | Purple-Violet Wash | purple / violet / UV-ish | Red slightly ↑, Green ↑, Blue ↓↓ |
| 08 | Magenta-Pink Wash | magenta / hot pink | Red ↓, Green ↑↑, Blue ↓ |
| 99 | Reset RGB Channel Curves | — | Sets the R/G/B curves back to linear. The master curve isn't touched. |

Each cast comes in three strengths: **1 Subtle**, **2 Medium** and **3 Strong**.

### How the curves are built

Every channel curve has 5 points (0, 64, 128, 192, 255), so you can adjust any of them by hand afterwards.

- **Midtone shift.** This is the main correction. The channel that matches the light is pulled down, and the channels the light starves are pushed up. Skin needs Red > Green > Blue, so when the presets restore missing colour, they lift red the most and blue the least.
- **Gentle S-shape on each channel.** LED washes flatten contrast within each channel, and a small S brings some separation back.
- **Lowered white point on the cast channel.** This tames clipped, fully saturated highlights in the light's colour, such as a red forehead under a red par.
- **Black point fixed at 0.** Shadows stay true black, so the stage background doesn't go muddy.

### Installing in Lightroom (desktop app, not Classic)

1. Download `dist/Concert-LED-Skin-Fix-Presets.zip`.
2. In Lightroom, go to **File → Import Profiles & Presets…** and choose the zip. You don't need to unzip it.
3. Open the Edit panel, click **Presets**, and look under **Yours → Concert LED Skin Fix**.

Presets you import into the desktop app sync through Adobe's cloud to Lightroom on mobile and on the web.

### Suggested workflow

1. Set white balance and exposure as usual. Often you'll just leave WB "As Shot", because stage light has no neutral reference.
2. Click the preset that matches the light colour on the performer's face, starting with **2 Medium**.
3. If the result is too much or too little, switch to **1 Subtle** or **3 Strong**. Each preset overwrites the R/G/B curves completely, so the strengths don't add up when you click one after another.
4. If a frame was lit by two colours, pick the preset for the colour that falls on the **skin**, then use a masked adjustment for the background if needed.

### Limits

Curves can only rebalance colour data the sensor actually recorded. Under a pure, saturated single-colour LED (deep red or deep blue), the missing channels contain almost nothing. In those frames these presets get skin from "glowing red/blue" to "warm but believable", not to studio-neutral. For the hardest frames, combine a preset with a lower Saturation/Luminance for that colour in Color Mixer, or with a black-and-white conversion.

### Tweaking or adding presets

Every preset is generated by `tools/generate_presets.py`. To change a cast, edit its numbers in the `CASTS` table (`shift`, `white`, `s`), or edit `STRENGTHS`, then run:

```sh
python3 tools/generate_presets.py
```

This regenerates `presets/Concert LED Skin Fix/*.xmp` and the zip. Preset UUIDs stay the same from run to run. If you re-import and see duplicates, delete the old group in Lightroom first.

## Lens Corrections preset

`presets/Lens Corrections/Lens Profile + Remove CA.xmp` (zipped as `dist/Lens-Corrections-Preset.zip`) sets exactly three things and nothing else:

| Setting | Value | Lightroom UI |
|---|---|---|
| `crs:LensProfileEnable` | `1` | Optics → **Use Profile Correction** on |
| `crs:LensProfileSetup` | `Auto` | Optics → Setup: **Auto** |
| `crs:AutoLateralCA` | `1` | Optics → **Remove Chromatic Aberration** on |

The preset deliberately does **not** name a specific lens. With Setup = Auto, Lightroom reads each photo's lens metadata (lens make/model, focal length, aperture, focus distance) and picks the matching profile per image, so one click works across every lens in a batch. The profile's Distortion and Vignetting amounts are left as they are (100 by default).

Notes:
- If Lightroom has no profile for a lens (manual lenses, adapted glass with no electronic contacts, missing metadata), profile correction stays on but has nothing to apply. Remove CA still works, because it doesn't need a profile.
- Many mirrorless raw files carry a built-in lens profile that Lightroom always applies. On those photos this preset just adds Remove CA.
- Install it the same way as the presets above: **File → Import Profiles & Presets…** and pick the `.xmp` or the zip. It appears under **Presets → Yours → Lens Corrections**.

## Concert Contrast + Fade presets

`presets/Concert Contrast + Fade/` (zipped as `dist/Concert-Contrast-Fade-Presets.zip`) has 19 contrast/fade combinations plus a reset, in the preset group **Concert Contrast + Fade**.

Each preset sets **only the master point curve** (the RGB/luminance curve in Point Curve mode), plus the curve's name label. These stay untouched:
- the Red/Green/Blue channel curves, so the presets stack with **Concert LED Skin Fix** in either order
- the parametric curve sliders
- Exposure, Contrast, Blacks and every other setting

### The grid

The name tells you the contrast level (**C**) and the fade level (**F**). For example, `C3 Strong - F2 Medium Fade` is strong contrast with a medium black fade.

| | F0 No Fade (black 0) | F1 Light Fade (black 12) | F2 Medium Fade (black 24) | F3 Heavy Fade (black 40) |
|---|---|---|---|---|
| **C0 Flat** (no S) | Reset Luminance Curve | ✓ | ✓ | ✓ |
| **C1 Soft** (S 8) | ✓ | ✓ | ✓ | ✓ |
| **C2 Medium** (S 14) | ✓ | ✓ | ✓ | ✓ |
| **C3 Strong** (S 20) | ✓ | ✓ | ✓ | ✓ |
| **C4 Punchy** (S 28) | ✓ | ✓ | ✓ | ✓ |

The **S** number is how far the curve darkens the shadows and brightens the light tones, measured in 0–255 levels at the strongest point. The midpoint (128 → 128) and the white point (255 → 255) never move, so overall brightness and highlights stay put.

The **black** number is the output level that pure black is lifted to, which gives a matte/film fade. The lift is strongest in the deep blacks and fades out through the shadows, so midtones barely move (+1 to +5) and highlights don't change at all. Shadows look washed out, but the rest of the image keeps its contrast.

### Tips for stage shots

- Black stage backgrounds turn charcoal from about **F2** up. **F1** is usually enough to soften crushed blacks without making the image look grey.
- Clicking a different preset in this group replaces the master curve. The effects don't add up.
- **Reset Luminance Curve** sets the master curve back to linear.

### Tweaking

Edit `CONTRAST`, `FADE` or `FADE_FALLOFF` in `tools/generate_contrast_presets.py`, then run:

```sh
python3 tools/generate_contrast_presets.py
```
